BMS Control Centre

About This Project

BMS Control Centre is a battery monitoring and management interface designed to monitor battery performance and system status.

System Information

Project: Battery Management System

Controller: ESP32

BMS: STM32

Firmware Version: v1.0.3

Hardware Version: REV B

Features

  • Live Battery Monitoring
  • Battery Telemetry
  • Battery Charts
  • Firmware Update
  • BMS Configuration
  • System Logs
  • Diagnostics

Version 1.0.0
